images/ 素材说明
================

本目录有两类素材：程序化生成的（脚本可复现）和实拍摄影的（由 photos/ 里的原图处理得到）。
两类素材都已写进 resources.qrc，构建时会一起打进 exe。


一、程序化生成素材（tools/gen_assets.py，纯 Python 标准库，无需 Pillow）

    moon.png        满月本体（512x512 透明底）
    mooncake.png    广式月饼俯视图（256x256 透明底）
    spark.png       金色光点粒子（64x64）
    glow.png        径向光晕（256x256）

    重新生成：python tools/gen_assets.py

    两个容易被忽略、但直接决定画面成败的细节（脚本里都写了注释）：

    1) moon.png 不出画"方形光晕"。
       早先的版本给月亮带了一圈一直铺到画布四角的暖色光晕，
       贴到实拍夜景上就会露出一个明显的方形亮块；而且四角的透明像素
       存成纯黑 (0,0,0,0)，Qt 做双线性缩放时会把黑边拖进月面，
       月亮周围就多出一圈脏兮兮的黑环。现在 moon.png 只保留月盘本体
       （透明像素也填暖白色，不是黑色），光晕交给代码里的 QRadialGradient。

    2) mooncake.png 的边不能画成"齿轮"。
       用 cos(16θ) 之类的公式做锯齿花边，画出来是一枚齿轮而不是月饼。
       现在是 10 瓣、振幅 2.4% 的柔和波浪边，再加模压凹槽、一圈连花圆点
       和中央印记，才是一块饼。


二、实拍摄影素材（本作品的主视觉，来源见 ../photos/）

程序对这几张图做了「可选加载」：先查 Qt 资源，再查 exe 同级的 images/ 目录；
两处都找不到就回退到矢量绘制。所以你也可以不重新编译，
直接把图片放到 exe 旁边的 images/ 文件夹里就能替换。

    school_night.jpg       软件学院夜景（1920x1080）
                           用于：启动页底图 / 主场景底图 / 小游戏楼前广场
                           原始照片是横构图被旋转 90° 存成竖图的，处理时已转正

    anyang_projection.jpg  安阳文峰塔夜景（1024x1024，正方形）
                           用于：月亮投影的「小家团圆 · 安阳文峰塔」圆幕
                           原图底部 62px 带微博水印，已整条裁掉

    yinxu_projection.jpg   殷墟博物馆（甲骨）夜景（512x512，正方形）
                           用于：月亮投影的「家国同庆 · 安阳殷墟甲骨」圆幕
                           原图正中有一道贯穿的「×」形半透明水印（两条 ±45° 细线），
                           用霍夫直线检测定位后做 inpaint 修补；原图为 3:2 横构图，
                           上下用垂直镜像延展、下半压暗成水面，补成 1:1

    ending_card.jpg        校训楼夜色（1920x1080）
                           用于：结尾页全屏底图

    ending_motto.png       原图书法「楼倚暮霞 德韵扬辉」抠字（494x253，透明底）
                           用于：结尾页右下角

    处理脚本：python tools/prep_photos.py（需要 Pillow；去水印与降噪另需 opencv-python；
              从 ../photos/ 读原图，向本目录写成品）

    处理要点：
      · 等比裁剪铺满（cover），不做拉伸，避免变形
      · 竖构图照片要转成横/方构图时，用「镜像延展 + 高斯模糊 + 压暗 + 中心清晰遮罩」，
        而不是直接拉伸
      · 3:2 横构图要补成 1:1 方幕时，主体居中、上下镜像延展、下半压暗成水面
      · 含文字的墙面（如校训墙）不参与镜像，否则镜像后会出现反写的字
      · 画面里的水印要真正除掉：文峰塔图是整条裁掉，殷墟图是霍夫定位后 inpaint


三、开启方式

    1) 把图片放进本目录；
    2) 打开 resources.qrc，取消对应那一行的注释；
    3) 重新构建。

    或（免重新构建）把图片放进 exe 所在目录下的 images/ 文件夹。

    本作品当前已把上表全部素材写入 resources.qrc 并启用。


四、原始照片归档

    ../photos/ 目录保留了四张原始照片（school_night_raw.jpg、anyang_tower_raw.jpg、
    campus_motto_raw.jpg、yinxu_museum_raw.webp）以及它们的处理脚本，
    方便复现或重新调整裁切范围。
