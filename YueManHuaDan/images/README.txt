images/ 素材说明
================

一、内置素材（必须保留，由 tools/gen_assets.py 生成，已加入 resources.qrc）

    moon.png        月亮（透明底，带环形山与边缘光晕）
    mooncake.png    月饼（透明底，酥皮花边 + 中央花纹）
    spark.png       金色光点粒子
    glow.png        径向光晕

    重新生成：python tools/gen_assets.py

二、可选写实素材（放了就自动生效）

程序对这三张图做了「可选加载」：先查 Qt 资源，再查 exe 同级的 images/ 目录；
两处都找不到就回退到矢量绘制。所以你也可以不重新编译，
直接把图片放到 exe 旁边的 images/ 文件夹里就能替换。

    school_night.jpg       软件学院夜景底图
                           有：替换掉矢量天空 + 教学楼 + 地面，作为写实底图，
                               月亮 / 月饼 / 电脑 / 投影 / 粒子仍叠在照片之上
                           建议：16:9，1920x1080 或以上

    anyang_projection.jpg  安阳投影画面（文峰塔 + 甲骨文「家」「国」+ 老家小院）
                           有：直接贴进月亮投影的圆形光幕里
                           建议：正方形，1024x1024
                           注：只用于「小家团圆」这一幕，其余两幕仍是矢量绘制

    ending_card.png        结尾祝福卡卡面
                           有：铺在祝福卡上（会压一层半透明红雾保证金字可读）
                           建议：600x196 左右，与卡面比例接近

三、开启方式

    1) 把图片放进本目录；
    2) 打开 resources.qrc，取消对应那一行的注释；
    3) 重新构建。

    或（免重新构建）把图片放进 exe 所在目录下的 images/ 文件夹。
